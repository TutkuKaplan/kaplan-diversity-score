# Kaplan Diversity Score (KDS)

The Kaplan Diversity Score (KDS) is a web-based analytical framework and digital assessment system for measuring structural diversity within organizations, institutions and projects.

## Purpose

The KDS was developed to make structural diversity measurable, comparable and transparent.

Instead of focusing exclusively on representation, the model examines three core structural factors:

- Power
- Visibility
- Spaces

## Core Framework

KDS evaluates how access, influence, visibility and institutional resources are distributed within organizational structures.

The model combines:

- standardized survey instruments
- coding matrices
- factor aggregation
- weighting dimensions
- automated interpretation

## Kaplan Diversity Metrics (KDM)

The extended framework allows the integration of additional structural factors and weighting dimensions while maintaining a normalized scoring logic.

Examples include:

- Social Background
- Care Responsibilities
- Neurodiversity
- Religion
- Education
- Custom institutional factors

## Application

The framework can be applied to:

- cultural institutions
- NGOs
- public administrations
- universities
- companies
- networks
- projects

## Digital Platform

The browser-based KDS platform allows users to:

- conduct surveys
- calculate scores
- compare results
- generate reports
- explore structural diversity indicators
